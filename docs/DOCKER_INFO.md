# Как работает Skeleton в docker

<p>Все приложения разрабатываемые на основе Skeleton разворачиваются внутри Docker контейнеров.<br>
Конфиги для сборки образов находятся в папке docker.<br>На основе имеющихся файлов происходит сборка и запуск контейнеров (app, mysql, nginx).<br>настройка и сбор приложения происходит на основе [docker-compose.yml](https://docs.docker.com/compose/).<br>

</p>

<ol>
    <li><strong>Создание базового образа приложения (base) на основе PHP (version):</strong>
        <ol>
           <li> Добавление в переменные окружения [токена GitLab](https://docs.gitlab.com/ee/user/profile/personal_access_tokens.html)</li>
           <li> Установка зависимостей и вспомогательных компонентов через apt (1-5 зависимости, 6-7 для удобства): 
              <ol>
                 <li> [libzip-dev](https://packages.debian.org/ru/sid/libzip-dev) - библиотека для чтения, модификации и создания зип архивов</li>
                 <li> [libgmp-dev](https://packages.debian.org/ru/sid/libgmp-dev) - библиотека для работы с числами длинной арифметики</li>
                 <li> [libicu-dev](https://packages.debian.org/ru/sid/libicu-dev) - библиотека для поддержки Unicode</li>
                 <li> [libpq-dev](https://packages.debian.org/ru/sid/libpq-dev) - это интерфейс PostgreSQL для программирования приложений на С</li>
                 <li> [libicu-dev](https://packages.debian.org/ru/sid/libicu-dev) - инструмент для управления zip-файлами</li>
                 <li> [iputils-ping](https://packages.debian.org/ru/sid/iputils-ping) - инструменты для проверки достижимости узлов в сети</li>
                 <li> [htop](https://htop.dev/) - утилита для вывода на терминал списка запущенных процессов и информации о них</li>
              </ol>
           </li>
           <li> Установка расширений php (как в 1.2):
              <ol>
                 <li> [intl](https://www.php.net/manual/ru/book.intl.php) - модуль интернационализации (позволяет производить настройки локали)</li>
                 <li> [opcache](https://www.php.net/manual/ru/book.opcache.php) - расширение PHP, предназначенное для повышения производительности PHP, сокращения времени загрузки веб-страниц и уменьшения нагрузки на сервере</li>
              </ol>
           </li>
           <li> Конфигурация intl и включение opcache</li>
           <li> Установка локалей оболочки</li>
           <li> Копирование Composer из образа Composer в директорию под Composer данного образа</li>
           <li> Обозначается директория и создается переменная PATH с путем до bin</li>
           <li> Копирование файлов проекта в контейнер</li>
           <li> Настройка Git на удаленный репозиторий и установка зависимостей Composer'a (стабильных, без скриптов, с отпимизацией автолодера)</li>
           <li> Запуск скрипта оболочки для всех пользователей</li>
           <li> В [entry point](https://docs.docker.com/engine/reference/builder/#entrypoint) определено использование оболочки Bash внутри контейнера, а также указывается скрипт, который должен выполняться при каждом его запуске.</li>
        </ol>
    </li>
    <li><strong>Создание dev версии образа на основе base образа:</strong>
        <ol>
           <li>Установка [xdebug](https://xdebug.org/) и его включение и прокидывание конфига в контейнер.</li>
           <li> Включение возможности обнуления вручную или рестартом веб-сервера</li>
           <li> Устанавливает php.ini-development в качестве php.ini в контейнере</li>
           <li> Копирование конфигов линтеров и тестов в контейнер</li>
        </ol>
    </li>
    <li><strong>Создание prod версии образа на основе base образа:</strong>
        <ol>
           <li> Изменяет владельца и группу для директории /var/www и всего содержимого на www-data:www-data.</li>
           <li> Добавляет правило в файл /etc/sudoers, которое позволяет пользователю www-data выполнять команду /usr/sbin/cron без необходимости вводить пароль при использовании sudo</li>
           <li> Отключение проверки временных меток файла в opcache для улучшения производительности</li>
           <li> Установка preload.php в качестве конфига для предварительной загрузки файлов. Сама предварительная загрузка нужная для ускорения выполнения скриптов</li>
           <li> Устанавливает php.ini-production в качестве php.ini в контейнере и чистит кэш пакетного менеджера и отменяет вывод команды в консоли при сборке</li>
        </ol>
    </li>
    <li><strong> При билде через Makefile Сначала запускается общий (базовый) docker-compose.yaml:</strong>
        <ol>
           <li> Создается app контейнер, который подключен к общей сети (ddh-network), в данный контейнер передается токен из .env.local</li>
           <li> Создается контейнер ${name}-frontend, в основе которого лежит образ nginx. Данный контейнер работает в двух сетях ddh-network (для работы c fpm) и [nginx-proxy](https://gitlab.hqsw.ru/ddh/nginx-proxy) для проксирования различных проектов в dev режиме по их локалхостам</li>
           <li> Создается volume ddh_public_data для хранения public даты</li>
        </ol>
    </li>
    <li><strong>Запускается docker-compose.dev.yml</strong>
        <ul>
           <li>dev:
              <ol>
                 <li> Создается app контейнер на основе определенного ранее Dockerfile определяется переменная hosts: host.docker.internal, который является специальным хостом в Docker для доступа к хостовой системе изнутри контейнера. host.docker.internal будет разрешен в IP-адрес хостовой системы, а host-gateway - это алиас для IP-адреса шлюза хостовой системы внутри контейнера</li>
                 <li> Создается переменная volume, в которой прописывается список томов, которые будут подключены контейнеру с конкретным местом монтирования</li>
                 <li> Создается контейнер на основе образа Mysql, который также подключен к сети ddh-network с целью обеспечения связи между контейнерами приложения, БД и nginx</li>
              </ol>   
           </li>
        </ul>
    </li>
</ol>

# Для локального переопределения/дополнения конфигурации docker-compose.(dev|prod).yml можно использовать файл docker-compose.override.yml
